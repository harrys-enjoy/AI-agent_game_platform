# Game Q&A 명령 입력창 설계

## 목표

명령 도움말에서 `/art`를 선택해도 긴 기본 프롬프트가 채팅 입력창을 차지하지 않도록 한다.

## 결정

- 명령 선택 시 입력창에는 선택한 명령어와 공백만 넣는다. 예: `/art `
- `/art`의 상세 안내와 기본 템플릿은 명령 도움말 및 명령어만 전송했을 때의 서버 처리에 유지한다.
- 사용자가 `/art 홍길동이 달빛 아래 등장하는 장면`처럼 주제를 바로 이어서 입력할 수 있어야 한다.

## 검증

- 명령 선택 함수가 `/art `를 설정하는지 단위 테스트한다.
- 기존 명령 해석 테스트와 프론트엔드 빌드를 실행한다.
