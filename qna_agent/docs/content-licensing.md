# 외부 게임 데이터 라이선스 정책

초기 카탈로그·도감·세계관 참고 데이터는 개별 원본 페이지에서 **CC0**가 명시된 자료만 사용한다. CC-BY, CC-BY-SA, GPL 등은 별도 검토와 의무 이행 절차가 마련되기 전까지 데이터에 넣지 않는다.

## 기록 원칙

- `data/sources.json`에 원본 제목, URL, 라이선스, 라이선스 URL, 사용 영역을 기록한다.
- `data/knowledge.json` 항목에는 해당 출처의 `sourceRef`를 남긴다.
- 원본의 설정·설명 범위를 넘어서는 세계관 서사를 작성하지 않는다.
- 원본의 미리보기 이미지는 라이선스가 별도일 수 있으므로, 다운로드 대상 파일의 라이선스만 기준으로 사용한다.
- CC0도 원저작권자가 실제 권리를 보유했는지에 대한 절대 보증은 아니므로, 출시 전 원본 페이지와 라이선스 전문을 다시 확인한다.

## 현재 시드 출처

- OpenGameArt `RPG Tileset` — CC0
- OpenGameArt `Free Game Objects` — CC0
- OpenGameArt `Starfields` — CC0

출처별 세부 URL과 라이선스는 [`data/sources.json`](../data/sources.json)에 보관한다.
