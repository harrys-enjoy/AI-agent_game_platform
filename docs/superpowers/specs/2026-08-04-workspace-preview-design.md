# Workspace Preview 디자인

## 목표

현재 Main Agent UI의 `Add code` 영역 아래에 로컬 파일을 선택하고 이미지 또는 코드를 넓게 확인할 수 있는 하단 가로형 미리보기 패널을 제공한다.

## 범위

- 브라우저에서 로컬 파일 선택
- 이미지 파일(PNG, JPG, JPEG, GIF, WebP) 미리보기
- 코드 파일(JS, TS, TSX, JSX, Python, Java, C#, JSON, YAML, Markdown 등) 읽기 전용 표시
- 여러 파일 선택 후 파일 목록에서 전환
- `Image`/`Code` 탭 전환
- 패널 열기/접기
- 서버 업로드나 영구 저장은 이번 범위에서 제외

## UI 설계

작업 테이블 아래에 전체 작업 영역 너비를 사용하는 `Workspace Preview` 카드를 배치한다. 카드 헤더에는 제목, 선택된 파일명, 접기 버튼을 둔다. 카드 본문에는 파일 선택 버튼과 파일 탭 목록을 배치하고, 아래에 미리보기 영역을 둔다.

파일을 선택하지 않은 경우 파일 추가 안내를 표시한다. 이미지 파일은 `img`로 표시하고, 코드 파일은 텍스트를 읽어 `pre` 영역에 표시한다. 미지원 파일은 파일명은 유지하되 미리보기 영역에 지원 형식 안내를 표시한다.

## 데이터 흐름

1. 사용자가 `Add code` 또는 파일 추가 버튼을 클릭한다.
2. 브라우저 `input[type=file]`에서 파일을 선택한다.
3. 선택 파일을 `PreviewFile` 상태로 정규화한다.
4. 이미지 파일은 object URL을 만들고, 코드 파일은 `File.text()`로 내용을 읽는다.
5. 선택된 파일과 유형에 맞는 뷰어를 렌더링한다.
6. 컴포넌트가 해제될 때 object URL을 정리한다.

## 오류 처리

- 읽기 실패 시 사용자에게 파일을 읽을 수 없다는 메시지를 표시한다.
- 지원하지 않는 확장자는 텍스트 내용을 임의로 표시하지 않고 지원 형식을 안내한다.
- 파일이 없는 취소 동작은 상태를 변경하지 않는다.

## 검증 기준

- `npm run build`가 성공한다.
- 이미지와 코드 파일을 추가했을 때 파일 탭이 생성된다.
- 이미지 선택 시 이미지 뷰어가 보인다.
- 코드 선택 시 코드 내용과 파일명이 보인다.
- 패널 접기/펼치기가 동작한다.
- 기존 AI Chat과 작업 테이블이 계속 렌더링된다.
