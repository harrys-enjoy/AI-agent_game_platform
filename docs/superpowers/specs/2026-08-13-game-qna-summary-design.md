# Game Q&A 작업 요약창 디자인

## 목표

Game Q&A 본문의 일반 Task 표를 제거하고, 채팅과 분리된 작업 요약 대시보드를 제공한다.

## 확정 범위

- Game Q&A 본문에서 Task/Owner/Status/Agent 표와 `+ Add task`를 제거한다.
- 채팅 패널의 질문·스토리 검토 입력은 유지한다.
- 본문에는 검토 대기, TXT 반영, 근거 부족, 최근 완료를 요약한다.
- TXT/스토리 입력은 기존 `+ Add story` 흐름을 유지하고, 본문은 그 결과 상태를 보여준다.
- 다른 Agent 화면과 사이드바의 기존 Task 기능은 변경하지 않는다.

## 화면 구성

1. 헤더: Game Q&A 작업 요약과 현재 지식 상태
2. 요약 카드: 검토 대기, TXT 반영, 근거 부족, 최근 완료
3. TXT 반영 패널: 업로드/검토/저장 상태와 마지막 반영 정보
4. 스토리 검토 패널: 세계관·캐릭터·퀘스트 검토 상태
5. 최근 작업: 작업명, 상태, 다음 행동

## 상호작용

- 채팅에서 입력한 질문은 오른쪽 채팅 패널에서 처리한다.
- `+ Add story`로 입력한 내용은 기존 스토리 검토 API를 사용한다.
- 검토가 필요한 RPG 콘텐츠는 상태를 요약창에 표시한다.
- 실제 Catalog/TXT API가 제공하지 않는 값은 임의로 성공 처리하지 않고 준비/연결 필요 상태로 표시한다.

## 성공 기준

- Game Q&A 선택 시 본문에 일반 Task 표가 보이지 않는다.
- TXT 업로드/스토리 검토 흐름은 기존 동작을 유지한다.
- 본문 요약창은 채팅 패널과 겹치지 않고 데스크톱·모바일에서 읽을 수 있다.
- 다른 Agent 화면의 레이아웃과 Task 동작은 회귀하지 않는다.
